# Neko

An interactive fiction game about surviving as a stray cat, built with [Twine](https://twinery.org/) and the [SugarCube 2](https://www.motoslave.net/sugarcube/2/) story format.

Play [Neko](https://raquelvinagre.github.io/Neko-Game/).

## Story

Explore the streets of city life as a stray cat. Make choices that affect your health, hunger, and trust in humans and other cats. Your decisions will determine your fate.

## Building the Game

Install the Twine Extension for Visual Studio Code, then open the `src/story.twee` file and run the build command to generate the `build/Neko.html` file.

## Running Locally

To run the game locally, you can simply open the `build/Neko.html` file in your web browser. No additional setup is required.
